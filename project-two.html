Tentang Proyek

Sistem Informasi Denah Pipa Gas di PT. PGAS Solution Ro Lampung

Proyek Sistem Informasi Denah Pipa Gas di PT. PGAS Solution Ro Lampung adalah sistem yang dikembangkan untuk mengelola dan memproses spesifikasi-spresifikasi mengenai pipa gas. Sistem ini memudahkan perusahaan untuk mengelola data spesifikasi dengan menggunakan library AJAX untuk dapat membuat 2 metode yaitu penambahan data dan perubahan data secara bersamaan

Peran dalam Proyek

Back-end Developer

Teknologi yang Digunakan

Frontend

Bootstrap CSS

Backend

Laravel Framework, Library AJAX

Database

MySQL

Fitur Utama

Admin dapat Menambahkan Data dan Mengubah Data Secara bersamaan

User Hanya dapat melihat Data Saja
